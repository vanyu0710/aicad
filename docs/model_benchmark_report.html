关键结论

  • 5/6 模型能驱动 varen 完成建模+逐件归档：Qwen3.8-Flash（120s）、DeepSeek-V4-Pro（122s，最快最干净 7 步）、DeepSeek-V4-Flash-Vision（169s）、GLM-5.3-Flash（320s）、GPT-5.6-Terra（326s）。
  • GPT-5.6-Sol 失败：流式 SSE 与 OpenAI 不兼容+陷入 design_calculate 调研循环，仅完成齿轮1、未建轴。需后端修流式聚合。
  • 成本提示：gpt-5.6-*每次请求自带 ~3700-4400 token 上下文（比其它模型高一个量级），长流程很贵；gpt-6-astra更贵，未测试。
  • 推荐：日常用 Qwen3.8-Flash（便宜稳）；复杂箱体/高质量用 DeepSeek-V4-Pro（推理强、步数最少）。
  • DeepSeek-V4-Pro 值得注意：生成的齿轮 STEP 仅 428KB（vs 其它 1.6MB），因为它对相同的 make_gear 可能走了不同齿形/参数路径，STEP 更精简。
