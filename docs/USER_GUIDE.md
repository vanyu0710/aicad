# Varen CAD IDE 新手使用教程

这份教程面向第一次使用 Varen CAD 的人。目标是让你从零开始完成一次“上传手绘草图，生成 3D 模型并导出 STEP/STL”的完整流程。

## 1. 如何启动

Windows 上最简单的方式：

1. 双击桌面上的 `Varen CAD IDE` 快捷方式。
2. 如果没有快捷方式，运行项目根目录下的 `start-mechcad-pro.cmd`。
3. 浏览器会自动打开 `http://127.0.0.1:8001/`。

开发模式也可以使用：

```powershell
.\start-mechcad.cmd
```

开发模式访问 `http://127.0.0.1:5173/`。

## 2. 启动页

第一次打开会进入启动页，包含：

- `新建项目`：开始一次新的 AI 建模。
- `最近项目`：打开以前做过的工作，也可以重命名或删除。
- 右下角可以切换界面语言：中文 / English。

如果没有配置任何 AI 模型，系统仍会走本地示例路径，方便你先把整个流程跑通。

## 3. 认识主界面

主界面按 SolidWorks 习惯设计，中间是 3D 工作区，四周是工具：

- 顶部：品牌、项目名、菜单、命令标签、状态、设置、撤销/重做、生成按钮。
- 左侧边缘：`特征`、`属性`、`配置` 三个入口，点击后从左侧浮出抽屉。
- 右侧边缘：`AI`、`评审`、`日志`、`导出` 四个入口，点击后从右侧浮出抽屉。
- 中央：3D 预览、视口工具、ViewCube、坐标轴、面包屑、状态。
- 底部：状态栏与快捷提示。

抽屉打开后：

- 拖拽抽屉边缘可以调整宽度。
- 点击 3D 空白处或按 `Esc` 可以关闭抽屉。
- 左右抽屉可以同时打开。

## 4. 第一次生成模型

按下面的顺序操作：

## 4. 第一次生成模型（v0.10 对话式）

1. 在启动页点击 `新建项目`。
2. 点击右侧边缘的 `AI`，打开 AI 助手抽屉。
3. （可选）在左侧 `特征` 抽屉上传手绘草图（PNG / JPG）——会话的**第一条消息**会自动带上它。
4. 在右侧聊天框直接下指令，例如：
   - "做一个 120×120×12 的法兰，中心 Ø30 通孔"
   - "外径 40mm，内径 30mm，长度 80mm 的套筒"
5. 按回车或点 `发送`。Agent 会在会话流里工作：模型文字逐字流式显示，每个工具调用是一张卡片（op / 参数 / 结果）。
6. 如果 Agent 需要确认，会话流顶部会弹出**审批卡 / 提问卡**，选择 **批准 / 改参 / 拒绝** 或直接输入答案。
7. **运行中也能继续说话**：聊天框始终可用，插话会在当前步骤结束后生效（例如"孔再大一点"）。
8. 3D 预览随几何变化自动刷新。

> 顶部 `生成 / 重算` 按钮和 `Ctrl+G` 只是把左侧表单里的描述作为一条会话消息发出——所有入口都是同一条对话。

## 5. 查看和导出模型

生成完成后：

- 中央 3D 视口会显示模型。
- 右下角可以直接下载 `STEP`、`STL`、`OBJ` 和执行报告。
- 右侧 `评审` 抽屉显示设计警告、制造建议、假设尺寸。
- 右侧 `日志` 抽屉显示 AI 和 CAD Worker 的执行过程。
- 右侧 `导出` 抽屉也有完整下载入口。

如果模型没有出现，先看右侧 `日志` 和 `评审`，通常原因包括：

- 仍有必答问题没有回答。
- 图纸缺少关键尺寸，严格模式下没有补数。
- CAD 执行失败，报告里会写明具体原因。

## 6. 修改模型

### 通过属性面板修改

1. 打开左侧 `特征` 抽屉。
2. 在特征树里点击一个特征，例如 `through_hole`。
3. 切换到左侧 `属性` 标签。
4. 修改尺寸后点击 `保存并重建`。

### 通过 AI 对话修改

打开右侧 `AI` 抽屉，在聊天框里直接说，例如：

- “把中心孔改成 12mm”
- “删除顶部槽”
- “新增 4 个 M6 孔，分布在 30mm 半径的圆上”
- “把底板厚度改成 8mm”

Agent 收到后会基于当前特征上下文继续建模（这条会话历史会保留，重开项目也能回看），
3D 预览会自动刷新。若 Agent 正在运行，消息会排队到它当前步骤结束后生效。

### 撤销和重做

- `Ctrl+Z`：撤销。
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做。
- 顶部工具栏也有撤销 / 重做按钮。

## 7. 配置 AI 模型

点击顶部 `设置`，或按 `Ctrl+,` 打开设置中心。

Varen CAD 把模型分为两类：

- 视觉模型：负责读取图纸，输出工程读图结果。
- 规划模型：负责把读图结果变成 FeaturePlan，也就是建模方案。

两类模型都支持 OpenAI / Anthropic 兼容接口，可以分别配置：

- Provider / Base URL / Model / API Key。
- 保存前可以先点击连接测试，确认配置可用。

如果只是体验流程，可以不配置，直接使用本地示例路径。

## 8. 模式说明

在设置中可以选择工作模式：

### 严格模式

- 只使用图纸上明确标注或用户确认的尺寸。
- 缺失尺寸时不会猜测，而是提问。
- 适合精度要求高的零件。

### 智能模式

- 在机械常识和图形比例基础上进行合理设计。
- 有三种自主程度：
  - `limited_fill`：工程保守设计，只补低风险概念尺寸。
  - `aggressive_fill`：概念快速生成，自动处理常见孔、槽、凸台、阵列。
  - `full_autonomous`：全自主方案设计，可以主动增加合理特征。

智能模式的所有推断都会写入假设和设计评审，不会悄悄使用。

## 9. 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+G` | 生成 / 重新计算模型 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+,` | 打开设置 |
| `Esc` | 关闭抽屉 |

## 10. 常见问题

### 模型和图纸不一致

先看右侧 `评审` 里的假设尺寸和未解决项。如果 AI 猜了尺寸，而你希望精确建模，请：

1. 在描述里把已知尺寸写完整。
2. 回答 AI 的所有确认问题。
3. 必要时切换到严格模式。

### 生成按钮看起来像卡住

先看右侧 `AI` 抽屉是否有待回答问题。严格模式遇到缺失尺寸时会停在等待确认状态，这不是卡死。

### CAD 报错

打开右侧 `日志` 或 `导出` 里的执行报告。报告会写明是哪个特征失败、跳过原因或布尔运算错误。旧模型不会伪装成本次成功结果。

### 3D 视图是空的

- 确认生成已经完成。
- 点击视口左上角 `Fit` 按钮。
- 检查右侧日志是否有失败信息。
- 如果页面很久没有刷新，按 `F5` 重新加载项目。

## 11. 一次完整的练习

建议用这个最小案例熟悉流程：

1. 新建项目。
2. 不传图片，只在描述里写：“一个 60mm x 30mm x 10mm 的底板，四角各有一个 5mm 通孔，孔中心距边缘 8mm。”
3. 点击生成。
4. 如果 AI 提问，依次回答。
5. 生成后在 3D 视口里旋转查看。
6. 下载 STEP 文件，用任意 CAD 查看器打开验证。

做完这一步，你就已经掌握了 Varen CAD 的核心工作流。
