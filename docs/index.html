Capabilities

模型写代码，几何归内核

复杂零件用脚本一次成型，但脚本只能调用内核公开 op——既拿到表达力，又守住"AI 不直接操纵几何"的边界。

⚙️

代码通道 run_build_script

箱体、阶梯轴、孔阵列这类多特征零件，模型写一段脚本一次完成，不用几十次原子 op 往返。

  • 脚本命名空间只暴露内核门面 k + math
  • AST 白名单：禁 import build123d / 禁下划线属性
  • 执行前检查点，失败整体回滚并回传原始 traceback
  • 脚本内 op 照常进特征历史 → 可参数重放
🔩

真实内核 MechKernel

背后是真实 OpenCascade 7.9.3 几何（Build123d），不是网格近似，也不是"假装建模"。

  • 34 公开 op：草图 → 拉伸 → 布尔 → 孔 → 阵列 → 齿轮 → 选边选面
  • make_gear 真渐开线齿形，大齿数按阈值回退
  • 每步 StepResult 结构化回读 + 几何证据
  • 事务 undo/redo + 参数化重放
🧩

多零件按位姿组装成装配体，导出带具名产品节点的 XCAF 装配 STEP，并做全对干涉检查。

  • 项目零件库：版本化归档 + 位姿 manifest

  • 全对干涉 + 齿轮啮合区豁免表

Quick start

三步，跑起来

Windows 桌面启动，无需 Docker。首次运行会自动构建前端并创建快捷方式。

  1. 装依赖

    Python 3.12 venv + 内核仓（真实 OCC 几何依赖 build123d / cadquery-ocp）。

  2. 配模型

    在 .env 填入 planner 模型（OpenAI 兼容端点即可），或在工作台设置中心配置。

  3. 启动并下指令

    双击桌面快捷方式，在右侧 AI 助手输入"做一块 120×120×12 法兰，中心 Ø30 通孔"。

# 1. 克隆两个仓库（IDE + 内核）
git clone https://github.com/vanyu0710/aicad
git clone https://github.com/vanyu0710/mechcad-kernel

# 2. Python 3.12 虚拟环境
cd aicad
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 3. 配置 planner 模型（任选 OpenAI 兼容端点）
echo MECHCAD_PLANNER_MODEL=your-model >> .env
echo MECHCAD_PLANNER_BASE_URL=https://your-endpoint/v1 >> .env
echo MECHCAD_PLANNER_API_KEY=sk-... >> .env

# 4. 产品模式启动（自动构建前端 + 托盘）
.\start-mechcad-pro.cmd
